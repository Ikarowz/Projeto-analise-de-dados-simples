# Análise de Dados Simples

Este projeto tem como objetivo realizar análises simples sobre conjuntos de dados utilizando técnicas de análise exploratória de dados (EDA) e visualizações. O foco principal é permitir a exploração de dados de forma rápida e eficaz, sem a complexidade de ferramentas mais avançadas.

## Funcionalidades

- Carregamento e pré-processamento de dados.
- Análise exploratória (estatísticas, distribuições, correlações).
- Visualização de dados (gráficos, diagramas, etc.).
- Cálculo de métricas chave (média, mediana, moda, desvio padrão, etc.).

## Tecnologias Utilizadas

- **Python**: Linguagem principal para análise e manipulação de dados.
- **Pandas**: Para análise e manipulação de dados tabulares.
- **Matplotlib**: Para visualização gráfica.
- **Seaborn**: Para visualizações estatísticas.
